# Privacy and safety — v2

Open registration replaces the invitation-only release by explicit owner decision. Adults provide mobile and email; neither requires verification until phase2. Signup, login and Account disclose this. CAPTCHA is mandatory on signup/login, using signed expiring single-use computational proof. It raises bot cost but does not verify identity. Unverified users can create multiple accounts and collude to flag profiles; operators need monitoring and appeals.

Dog profiles publish without prior approval once eligible, available and photo-present. More than10 distinct unresolved reporters automatically suspend a dog. Repeat reports from one account count once. Suspension survives edits/uploads. Operators can manually suspend/reinstate, remove photos with reasons and resolve reports, with audit records.

Email/mobile stay private until a per-channel grant to an accepted active connection. Acceptance, CAPTCHA and chat do not automatically share contacts. Mobile is mandatory for signup/account updates; legacy empty values do not block login. No verified badges. Owners may voluntarily type contact details in chat; recipients can copy them. Public dog text should not include personal contacts, addresses or sensitive records.

Chat belongs to a connection's two owners. Every live read/send checks participants, acceptance, eligibility, availability, blocks, suspension and archive state. Closing/blocking removes live access, but cannot erase previously copied messages. Participants can report a specific received message after restriction; operators see only that reported snapshot and report details, without general chat-history access. Own export includes previously shared conversation history, including closed threads. Unrelated data and withheld contacts never export. Deletion cascades messages, read state, photos and related reports; deidentified audit remains. Messages are retained until either participant deletes the account; no time-based purge exists yet. Backup deletion follows copy rotation. Jurisdiction, lawful notices, staffing, appeals and retention remain owner decisions.

JPEG/PNG/WebP: validate decoded data, max5MB/16MP, resize to1600px longest edge, re-encode JPEG without metadata. Authenticated reads enforce visibility except owner/operator moderation access. Coordinates are rounded before persistence; other owners see only city/distance bands. No exact location or contact details in chat DTOs. HTTPS is used; there is no E2EE claim. Server credentials and CAPTCHA key stay in Secret Manager; operational logs contain no private message/contact payloads. Rate limiting is per process. Health claims remain self-declared, without suitability certification. No payments, puppy marketplace or breeding recommendations.

Theme preference is Light/Dark/System and device-local. Web stores only the theme preference, never its auth token; native uses secure storage. System follows OS changes. Phase2 includes contact verification and recovery/provider choices. Current release documents distinguish executed checks from unperformed device/load/restore tests.
